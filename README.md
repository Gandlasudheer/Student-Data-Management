****Student Record Management System**

Developed by: GANDLA SUDHEER

Mini Project – I | C Programming

**Project Overview**

The Student Record Management System is a menu-driven application developed using C programming. It manages student information using a Singly Linked List, Dynamic Memory Allocation, Searching, Sorting, and File Handling.

**Developer Information**

- Name: GANDLA SUDHEER
- Project Title: Student Record Management System
- Project Type: Mini Project – I
- Programming Language: C
- Data Structure: Singly Linked List
- Compiler: GCC

**Key Features**
- Add new student records.
- Automatically assign unique roll numbers.
- Delete student records.
- Display all student records.
- Modify student details.
- Search student records.
- Sort records by name and percentage.
- Reverse the linked list.
- Save and load records using "student.dat".
- Manage memory dynamically.

**Compilation**

gcc stud_main.c stud_add.c stud_del.c stud_show.c stud_mod.c stud_save.c stud_sort.c stud_reverse.c -o student

**Execution**
./student

**Concepts Used**

- Structures and Pointers
- Singly Linked Lists
- Dynamic Memory Allocation
- Modular Programming
- Searching and Sorting
- File Handling
- Memory Management

**Conclusion**

This project demonstrates the practical implementation of important C programming concepts through a student record management application.
